# Arc RPC Sentinel 🛰

Free multi-node RPC watchdog for the Arc network — Telegram bot.

## Features
- Pings 4 RPC endpoints every 5 min (block height + latency)
- Instant alerts: node down / recovered / network-wide outage
- Commands: /status (live dashboard), /ping, /best (fastest node)
- 10 languages, inline keyboard, HTML dashboard
- On watch since Arc mainnet launch, 16 Sep 2026
